# Syria & World News Intelligence — V1.0

واجهة عربية أولية لرصد الأخبار من خلاصات Google News RSS، مع تصنيف آلي أولي، تقدير أهمية، بحث وفلاتر وحفظ محلي للمواد.

## ما تتضمنه النسخة
- رصد: سوريا، تركيا، الولايات المتحدة، روسيا، الأمم المتحدة، إيران، إسرائيل، لبنان.
- تصنيفات أولية: سياسي، عسكري، أمني، دبلوماسي، اقتصادي، طاقة، إنساني، عام.
- مستويات أهمية أولية: عاجل، مهم، عادي.
- إزالة تكرار بسيطة، بحث، فلاتر، روابط للمصادر، وحفظ المواد في متصفح المستخدم.
- واجهة متجاوبة للكمبيوتر والهاتف.

## التشغيل المحلي
يتطلب Node.js 18 أو أحدث.

```bash
npm install
npx vercel dev
```

## النشر على Vercel
1. ارفع محتويات هذا المشروع إلى جذر مستودع GitHub.
2. استورد المستودع من لوحة Vercel.
3. اترك إعدادات البناء الافتراضية؛ لا يوجد أمر Build مطلوب لهذا الإصدار.
4. انشر المشروع.

## حدود النسخة الأولى
- RSS يوفّر عناوين ومقتطفات وروابط، وليس ضماناً للوصول إلى النص الكامل للمقالات.
- لا يوجد في هذه النسخة تلخيص توليدي أو ترجمة مضمونة لكل مادة؛ لا ندّعي ذلك.
- تصنيف الخبر وتقدير أهميته يعتمدان على كلمات مفتاحية، ويجب مراجعتهما تحريرياً.
- لا يوجد تسجيل دخول في هذه النسخة. لا تنشرها للعامة للاستخدام التحريري الحساس قبل إضافة حماية دخول.
- لا يوجد بعد أرشيف مركزي دائم أو تنبيهات فورية أو موجز صباحي مجدول؛ المحفوظات الحالية محلية في المتصفح.
- Google News RSS مصدر تجميعي؛ افتح دائماً رابط الناشر الأصلي وتحقق من الخبر قبل البث.

## ملاحظة أمنية
لا تضع مفاتيح API أو كلمات مرور في ملفات الواجهة أو مستودع GitHub. أي تكامل ذكاء اصطناعي لاحق يجب أن يستخدم متغيرات بيئة على الخادم.
